ЛЕКСИКОН — англо-русский словарь для Windows 7, 8, 10, 11

КАК ЗАПУСТИТЬ
1. Распакуйте архив: правой кнопкой по Lexikon-Windows.zip → «Извлечь все…» → «Извлечь».
2. Откройте распакованную папку Lexikon и дважды щёлкните по файлу Start-Lexikon.bat.
3. Словарь сам откроется в браузере. Интернет не нужен.

Пока пользуетесь словарём, не закрывайте чёрное окно — это и есть словарь.
Чтобы выключить — закройте это окно.

НУЖЕН БРАУЗЕР
Google Chrome, Microsoft Edge, Яндекс Браузер или Mozilla Firefox (Internet Explorer не подходит).
Для Windows 7: Chrome 109, Edge 109 или Firefox 115 — последние версии для этой системы.

ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ
• «Предупреждение системы безопасности» → нажмите «Запустить».
• Синее окно «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
