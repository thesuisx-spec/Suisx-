# おちることば · Падающие слова

Браузерная игра для запоминания слов из учебника **Minna no Nihongo I** (для русскоговорящих).

Сверху падают слова хираганой, снизу — варианты перевода. Выбери правильный перевод
(мышкой, пальцем или клавишами 1–6), пока слово не упало в воду.

- 25 уровней = 25 уроков учебника; можно начать с любого
- 5 жизней-сакур, комбо, очки, до 3 звёзд за урок (прогресс сохраняется в браузере)
- Пропущенные слова возвращаются в очередь и показываются в конце для повторения
- Три скорости, звук и японская озвучка слов (если в системе есть японский голос)

## Запуск

Открой `index.html` в браузере — установка не нужна.
