# おちることば · Японский в классе

Помощник учителя японского языка в одном приложении (один файл `index.html`). Два раздела:

1. **かな · Азбука** — хирагана и катакана по рядам.
2. **ことば · Слова** — игра «Падающие слова» по учебнику **Minna no Nihongo I** (для русскоговорящих).

## Азбука
- Ряды идут этапами: あ・か・さ → た・な・は → ま・や・ら → わ・を・ん, дополнительно — звонкие が・ざ・だ・ば・ぱ.
- Урок ряда: большая буква на клетке, анимация порядка черт с номерами, чтение по-русски (Поливанов) и ромадзи,
  озвучка, «обвести пальцем», переключение хирагана ↔ катакана, пример слова с переводом и кандзи.
- После каждых трёх рядов — игра **«Порядок» (順番)**: буквы стоят вперемешку, класс читает слева направо.
  «✓ Прочитал» (пробел или нажать на букву), «✗ Ошибка» (X) — всё сначала, «Перемешать» (S).
  Учитель выбирает, показывать ли чтение: нет / у прочитанных / у всех. Время и рекорд класса сохраняются.
- Порядок черт: [KanjiVG](https://kanjivg.tagaini.net) © Ulrich Apel, лицензия CC BY-SA 3.0.

## Слова
Сверху падают слова, снизу — варианты ответа. Выбери правильный (мышкой, пальцем или клавишами 1–6),
пока слово не упало.

## Главы и сцены
25 уроков разбиты на 5 глав, у каждой своя анимированная сцена, свои таблички и частицы:

| Глава | Уроки | Сцена |
|---|---|---|
| 春 Весна | 1–5 | Фудзи, луна, тории, падающая сакура |
| 夏 Мацури | 6–10 | летний фестиваль, фонари, салют, светлячки |
| 秋 Момидзи | 11–15 | закат, пагода, клёны, падающие листья |
| 冬 Снег | 16–20 | горная деревня, снегопад |
| 夜 Токио | 21–25 | неоновый город, Токийская башня, дождь |

## Режимы
- **Уроки** — 5 жизней, до 3 звёзд за урок
- **Направление** — «日本語 → русский» или «русский → 日本語»
- **Мои ошибки** — пропущенные и перепутанные слова; слово уходит из списка после 3 правильных ответов подряд
- **Экзамен** — слова из выбранного диапазона уроков, до 40 слов, 3 жизни
- **Бесконечный режим** — слова пройденных уроков, скорость растёт, сцена меняется каждые 20 слов, рекорд сохраняется

После правильного ответа показывается запись слова кандзи (если она есть).
Иногда падают золотые бонусы (клик или пробел): 遅 — замедление, 命 — +1 жизнь, 爆 — бомба, убирает все слова.

## Запуск
Открой `index.html` в браузере — установка не нужна.
