# おちることば · Японский в классе

Помощник учителя японского языка в одном приложении (один файл `index.html`). Два раздела:

1. **かな · Азбука** — хирагана и катакана по рядам.
2. **ことば · Слова** — игра «Падающие слова» по учебнику **Minna no Nihongo I** (для русскоговорящих).

## Азбука
- Ряды идут этапами: あ・か・さ → た・な・は → ま・や・ら → わ・を・ん, дополнительно — звонкие が・ざ・だ・ば・ぱ.
- Урок ряда: большая буква на клетке, анимация порядка черт с номерами, чтение по-русски (Поливанов) и ромадзи,
  озвучка, «обвести пальцем», переключение хирагана ↔ катакана, пример слова с переводом и кандзи.
- После каждых трёх рядов — игра **«Порядок» (順番)**: буквы стоят вперемешку, класс читает слева направо.
  «✓ Прочитал» (пробел или нажать на букву), «✗ Ошибка» (X) — всё сначала, «Перемешать» (S).
  Учитель выбирает, показывать ли чтение: нет / у прочитанных / у всех. Время и рекорд класса сохраняются.
- Порядок черт: [KanjiVG](https://kanjivg.tagaini.net) © Ulrich Apel, лицензия CC BY-SA 3.0.

## Слова
Сверху падают слова, снизу — варианты ответа. Выбери правильный (мышкой, пальцем или клавишами 1–6),
пока слово не упало.

## Главы и сцены
25 уроков разбиты на 5 глав, у каждой своя анимированная сцена, свои таблички и частицы:

| Глава | Уроки | Сцена |
|---|---|---|
| 春 Весна | 1–5 | Фудзи, луна, тории, падающая сакура |
| 夏 Мацури | 6–10 | летний фестиваль, фонари, салют, светлячки |
| 秋 Момидзи | 11–15 | закат, пагода, клёны, падающие листья |
| 冬 Снег | 16–20 | горная деревня, снегопад |
| 夜 Токио | 21–25 | неоновый город, Токийская башня, дождь |

## Режимы
- **Уроки** — 5 жизней, до 3 звёзд за урок
- **Направление** — «日本語 → русский» или «русский → 日本語»
- **Мои ошибки** — пропущенные и перепутанные слова; слово уходит из списка после 3 правильных ответов подряд
- **Экзамен** — слова из выбранного диапазона уроков, до 40 слов, 3 жизни
- **Бесконечный режим** — слова пройденных уроков, скорость растёт, сцена меняется каждые 20 слов, рекорд сохраняется

После правильного ответа показывается запись слова кандзи (если она есть).
Иногда падают золотые бонусы (клик или пробел): 遅 — замедление, 命 — +1 жизнь, 爆 — бомба, убирает все слова.

## Запуск
Открой `index.html` в браузере — установка не нужна.

# Лексикон · английский словарь (`dictionary/`)

Англо-русский веб-словарь (PWA) в духе больших онлайн-словарей: один поиск, толкование и перевод в одной статье.

- **Толковый EN** — значения по частям речи, примеры, синонимы и антонимы.
- **Англо-русский** — переводы по значениям, с родом (м./ж./ср.) и видом глагола (сов./несов.), ударениями.
- **Обратный поиск** — можно вводить русские слова (кошка) и получать английские значения.
- Произношение **UK / US**: транскрипция и аудио (если записи нет — голос браузера). Русские переводы тоже озвучиваются.
- Подсказки при вводе (стрелки + Enter), «Похожие слова», слово дня, двойной щелчок по любому слову открывает его статью, `/` — перейти к поиску.
- **Избранное** и **история** (по дням) хранятся в браузере.
- Светлая и тёмная тема, мобильная версия, установка на телефон и офлайн-доступ к уже открытым словам.

## Офлайн
Словарная база лежит в `dictionary/data/` и собирается скриптом из открытых выгрузок Wiktionary (kaikki.org):

```bash
pip install wordfreq
python3 dictionary/tools/build_dict.py      # скачивает English и Russian JSONL с kaikki.org
```

База разбита на небольшие сжатые файлы: статья подгружается мгновенно, а кнопка «Скачать весь словарь»
на главной сохраняет всю базу на устройство, после чего интернет не нужен. Если слова нет в базе и есть интернет,
приложение ищет его в онлайн-источниках.

Запуск: через любой статический сервер по https или localhost (GitHub Pages, `npx serve dictionary`).
При открытии файла двойным щелчком офлайн-хранилище браузера недоступно.

Данные из открытых источников: [Free Dictionary API](https://dictionaryapi.dev),
[Wiktionary](https://en.wiktionary.org) (CC BY-SA 4.0), [Datamuse](https://www.datamuse.com/api/).

## Программа для Windows 7, 8, 10, 11 (`desktop/`)

Тот же словарь в собственном окне (Electron 22 — последняя версия с поддержкой Windows 7), база внутри, интернет не нужен.
GitHub Actions собирают установщики на каждое изменение:

- [Lexikon-Setup.exe](https://github.com/thesuisx-spec/Suisx-/releases/download/lexikon-app/Lexikon-Setup.exe) — установка в один клик, без прав администратора, ярлык на рабочем столе;
- [Lexikon-Setup-32bit.exe](https://github.com/thesuisx-spec/Suisx-/releases/download/lexikon-app/Lexikon-Setup-32bit.exe) — для 32-битной Windows;
- [Lexikon-Portable.zip](https://github.com/thesuisx-spec/Suisx-/releases/download/lexikon-app/Lexikon-Portable.zip) — без установки: распаковать и запустить `Lexikon.exe`.

Локально: `cd desktop && npm install && npm start`.

# HSK · 汉语 — китайский по уровням HSK 1–6 (`hsk/`)

Сайт-приложение для учителя китайского и учеников: все слова экзамена HSK с переводом на русский,
озвучкой, видеоуроками для класса, аудированием, порядком черт, грамматикой и пробными тестами.

**Открыть:** `hsk/index.html` в браузере (Chrome, Edge, Safari, Яндекс Браузер) — установка не нужна.
Опубликовать для учеников по ссылке: GitHub → Settings → Pages → Deploy from a branch → ветка с приложением, папка `/ (root)`;
адрес будет `https://<пользователь>.github.io/Suisx-/hsk/`. На сайте приложение можно «установить» на телефон и открывать без интернета.

## Два стандарта, уровни 1–6
- **HSK 3.0 (программа 2026 г.)** — новый экзамен: 300 / 500 / 1000 / 2000 / 3600 / 5400 слов нарастающим итогом.
- **HSK 2.0** — классический экзамен и учебники HSK Standard Course: 150 / 300 / 600 / 1200 / 2500 / 5000 слов.

Переключатель вверху справа. Каждый уровень разбит на уроки по 15–25 слов (сначала самые частотные).
Всего 7018 слов, у каждого — пиньинь с цветными тонами, перевод на русский, часть речи, счётное слово, полная форма.

## Аудио и видео
- **Каждое слово звучит.** Где есть — запись носителя языка из Wikimedia Commons (Викисловарь и Lingua Libre),
  иначе голос браузера; есть медленная скорость.
- **Видеоурок** — урок проигрывается сам: иероглиф рисуется по чертам, слово звучит, появляются пиньинь и перевод,
  пауза «Повторите!», пример предложения. Во весь экран — для проектора; через запись экрана — готовое видео для учеников.
- **«Слушать урок»** — аудиоурок: каждое слово дважды и перевод русским голосом.
- **Примеры предложений** (Tatoeba) с пиньинем и переводом, подобраны под уровень, озвучиваются.

## Упражнения и материалы
- **Карточки** (иероглиф → перевод, перевод → иероглиф, на слух) с отметкой «выучено».
- **Аудирование**: какое слово прозвучало, что оно значит, какие тоны, диктант пиньинем, предложения на слух; «Мои ошибки».
- **Иероглифы уровня**: анимация порядка черт и письмо пальцем/мышью с проверкой.
- **Грамматика** каждого уровня: формула, объяснение, примеры вслух.
- **Пробный тест** из 20 заданий (听力 + 阅读), лучший результат сохраняется.
- **Пиньинь и тоны**: все слоги с озвучкой, тренажёр тонов, правила чтения.
- **Печать**: список слов, контрольные, прописи с порядком черт.
